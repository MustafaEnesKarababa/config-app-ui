Proje Adı: config-app-ui

Proje Açıklaması:
config-app-ui, React tabanlı bir kullanıcı arayüzü uygulamasıdır. Admin kullanıcılarının konfigürasyonları listelemelerini, yeni konfigürasyonlar eklemelerini, mevcutları güncellemelerini ve silmelerini sağlar. Bu uygulama, ConfigAdminApi API'si ile etkileşime geçer ve kullanıcıların konfigürasyonları yönetmesini sağlar.

Kurulum:
  1- Projeyi indirin veya klonlayın
  2- Api projesinin çalıştığından emin olun
  3- Gerekli bağımlılıkları yükleyin
        npm install
  4- Uygulamayı başlatın
        npm start
  5- ../src/admin/api/configApi.js dosyasında bulunan baseURL'i kendi local Api url'iniz ile değiştirin.

Kullanım:
Admin kullanıcıları, konfigürasyonları görüntüleyebilir, yeni konfigürasyonlar ekleyebilir, mevcutları güncelleyebilir ve silebilir.

Arayüz, ConfigAdminApi API'sine bağlanarak verileri çeker ve kullanıcı etkileşimlerini işler.

Teknolojiler:
  React.js: Kullanıcı arayüzünü oluşturmak için kullanılmıştır.
  Axios: API istekleri için kullanılmıştır.
